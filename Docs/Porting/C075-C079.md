# Porting plan: C075 to C079 (branch `claude/port-c075`)

Chain off C074 (`4c9fcdedf448`, v0.26.7). The chain runs backwards in release time: v0.26.5/6 -> v0.26.0-beta4 -> beta3 -> beta1/2 -> v0.25.x.
In `Tools/ClassDigest.py` output `-` lines are the parent (newer) code and `+` lines the class (older) code; the flag for the class edge
therefore restores the OLDER upstream behaviour, so name flags after the PR that introduced the NEWER behaviour and make `rules.has(X)` true
for the newer one (parent side), as in CLAUDE.md. Engine edits wait for the coordinator's restructure of `Builds/Rules.rs` and `Config.rs`;
the digest text for FakeHumanExecution, BotBehavior and DefaultConfig names Rust modules as "no port found" only because of path mapping
(`Crates/Engine/src/Execution/FakeHumanExecution.rs` etc. exist); check with grep first.
