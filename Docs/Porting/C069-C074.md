# Porting plan: C069 to C074

Agent notes, English only. Digests come from `Tools/ClassDigest.py <class>`: `-` lines are the parent's code, `+` lines are the class's. The chain runs against release time (C069 is v0.26.14, its parent C068 is v0.27.0-beta2), so almost every edge here is a **reversion** of a feature the Rust baseline (v0.34.22) already has. Each flag below is therefore "newer behaviour" (`rules.has(X)` true) that the class edge **removes** from its parent, unless noted. Check `Rules.rs` first: C064 to C068 (other workers) or the baseline may already define the flag.

Nation code lives in `Execution/NationExecution.rs`, `Execution/Nation/*.rs`, `Execution/TribeExecution.rs`, `Execution/Utils/{AiAttackBehavior,PlayerSpawner}.rs` (upstream `FakeHumanExecution`, `BotExecution`, `BotBehavior`).
