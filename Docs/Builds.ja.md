# 運用されたビルド一覧 (2025-10-01 から 2026-11-11)

責務: 公開ゲーム記録の `gitCommit` に現れた upstream OpenFront のビルドと、シミュレータに関係するエンジン上の事実を一覧にする。

## 方法

- データ: 公開 API (`/public/games`, `/public/game/<id>`)。2025-10-01 から 2026-11-11 までの各 UTC 日について 06:00-06:20 と 18:00-18:20 の 2 窓を列挙し、各窓で最短の Public と最短の非 Public (Singleplayer) を取得した。記録が 3 件未満のビルドは、目撃時刻の前後 6 時間以内の最短ゲームを追加取得した。
- ホールドアウト日 2026-10-02 (UTC) は一切取得していない (スクリプトでガード済み、該当記録 0 件)。その日だけ運用されたビルドは見えない。
- 記録 2088 件、異なるビルド 159 個。記録は git 管理外の `Cache/Records/<commit12>/<gameId>.json.gz`、索引は `Cache/Records/Index.csv`。
- タグ: コミットを指す正確なタグ (`git tag --points-at`)。無い場合は最寄りタグ (`git describe`) とそれを含む最初のタグ。「main の祖先」は `git merge-base --is-ancestor <commit> origin/main`。リリースブランチ上のタグは通常 main の祖先ではない。
- PRNG / DetMath: 当該コミットのツリーから判定 (`PseudoRandom.ts` が sfc32 か seedrandom か、`DetMath.ts` の有無)。モノレポ分割 (upstream e82286146) でパスが変わったため、ファイル名で検索した。
- records 列: 合計 (Public/その他; FFA/チーム)。

## 結果

- サンプルしたビルドはほぼすべてタグ付きの upstream リリース (159 個中 158 個)。タグ無しは `a26585a47b17` の 1 件 (記録 1 件のみ)。ベータや test-release も公開ゲームで使われた (`v0.26.0-beta1..4`, `v0.27.0-beta2`, `v0.29.0-beta1..4`, `v0.30.0-beta1/2/5`, `v0.32.0-beta1/3/5/6`, `v0.34.0-test-release`)。
- ビルドは時間的に単純な順序ではない。多くの日で 2 つ以上のビルドが Public ゲームを生成している (例: 2025-10-04 から 10-14 は `bc5f18dee882`, `fd6b0ee062e2`, `136cfa1316dd` が交互に現れ、同日でも 06:00 窓と 18:00 窓で異なる)。ロールバックもある (`82ff4e43c1e1` の後 2025-11-12 から 18 に `4c9fcdedf448` が再出現)。Singleplayer の記録はクライアントのビルドのコミットを持ち、サーバーと前後しうる。したがってシミュレータは日付ではなく各記録自身の `gitCommit` でエンジンを選ぶ必要がある。
- 数時間から数日しか使われないビルドが多い (サンプル 1 件のビルドが 15 個、2 件が 1 個)。この一覧は運用ビルドの下限であり網羅ではない。
- リリース頻度は 2026-09 から急増 (2026-09-14 に v0.34.0、以降 v0.34.x がほぼ毎日)。
- PRNG: 旧アルゴリズムは `seedrandom` (npm パッケージ、既定の ARC4 ストリーム暗号、`String(seed)` で初期化)。upstream 2e6f70c09 (PR #4233, 2026-06-12) まで使用。以降の `PseudoRandom` は sfc32 をインライン実装し、splitmix32 で初期化して 12 回空読みする。初めて確認した sfc32 ビルド: `5be72db060fc` (2026-06-15, v0.32.0-beta5)。
- DetMath (決定的な `exp/log/pow/atan2`) は upstream f2c9a5378 (PR #5191, 2026-08-30) から。初めて確認したビルド: `1e973bb534b8` (2026-09-14, v0.34.0)。それ以前は素の `Math.*` を使うため、超越関数の結果を bit 単位で再現する際は注意が必要。
- 件数: seedrandom かつ DetMath なし 88 個、sfc32 かつ DetMath なし 36 個、sfc32 かつ DetMath あり 35 個。
- ベースライン `4e837520e886` (v0.34.22) の初出は 2026-10-03。2026-10-02 はホールドアウト。
